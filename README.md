# CEG2136 — Computer Architecture I

University of Ottawa | Spring/Summer 2024

A collection of five course laboratories covering digital logic design, simulation, and FPGA-based implementation. Labs will be added individually as their project files and supporting documentation become available.

## Labs

| Lab | Topic | Contents |
| --- | --- | --- |
| [Lab 0](labs/lab-00-quartus-ii-full-adder/) | Quartus II introduction and 1-bit full adder | Quartus project, full-adder logic, waveform setup, and FPGA verification documentation |

## Organization

Each lab has its own README, original editable design sources, a report (where available), and evidence images. Disposable Quartus build artifacts are excluded.

## Academic context

These are coursework materials archived for documentation and portfolio purposes, not a turnkey library. Hardware and simulation results are described in the original reports. Collaborators are credited in the lab reports.
