# Lab 2 — Synchronous Counters

## Overview

Designed synchronous counters using **JK flip-flops**, excitation tables and Karnaugh maps.

| Circuit | State range | Implementation |
| --- | --- | --- |
| BCD counter | 0–9 | Four JK flip-flops |
| Modulo-6 counter | 0–5 | Three JK flip-flops |
| Modulo-60 counter | 0–59 | Cascaded modulo-10 and modulo-6 stages |

## Verification

The report includes state and excitation tables, logic diagrams, simulated waveforms and discussion of the counter designs.
