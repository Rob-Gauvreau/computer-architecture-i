# Lab 0 — Laboratory Report

This folder contains the report for **Lab 0: Quartus II Introduction — 1-Bit Full Adder**, completed for CEG2136 (Computer Architecture I) at the University of Ottawa.

## Report

- **[Lab Report 0 CEG2136.pdf](Lab%20Report%200%20CEG2136.pdf)** — original laboratory report documenting the full-adder design and verification.

## Contents

The report presents:

- The design objective and the operation of a one-bit full adder.
- The truth table and Boolean expressions for sum and carry-out.
- Gate-level circuit design in Quartus II.
- Functional waveform simulation and compilation results.
- FPGA implementation and hardware test observations using the Terasic DE2-115 development board.
- Comparison of theoretical and experimental results, followed by discussion and conclusions.

The experiment examines all eight combinations of `A`, `B` and carry-in (`Cin`) to verify the expected sum and carry-out responses.

The matching schematic, simulation screenshot, compilation screenshot and hardware photographs are available in the [images folder](../images/). The editable Quartus project files are in [`quartus/`](../quartus/).
