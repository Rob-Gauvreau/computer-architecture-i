# CEG2136 — Computer Architecture I

University of Ottawa | Spring/Summer 2024

A collection of five course laboratories covering digital logic design, simulation, and FPGA-based implementation. Labs are added as project sources and documentation become available.

## Labs

| Lab | Topic | Contents |
| --- | --- | --- |
| [Lab 0](labs/lab-00-quartus-ii-full-adder/) | Quartus II introduction and 1-bit full adder | FPGA schematic, waveform, pin assignments, verification documentation |
| [Lab 1](labs/lab-01-enabled-decoder/) | Simple logic design / enabled 2-to-4 decoder | Quartus gate-level schematic, waveform, Boolean logic, verification documentation |

## Organization

Each lab contains its editable Quartus design in `quartus/` and a technical README. Photographs, diagrams, and reports are archived separately for manual binary upload until they can be published through the connected integration. Disposable Quartus build artifacts are excluded.

## Academic context

These are coursework materials archived for documentation and portfolio purposes. Hardware and simulation results are based on the original lab reports. Please consult each lab's README for source notes and limitations.
