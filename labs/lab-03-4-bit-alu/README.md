# Lab 3 — 4-Bit Arithmetic Logic Unit

## Overview

Developed a hierarchical **4-bit arithmetic logic unit (ALU)** in Quartus II, starting with 1-bit circuits and combining them into 4-bit components.

The ALU covers:

- **Arithmetic:** addition and subtraction.
- **Logic:** bitwise AND, OR and XOR.
- **Shifting:** left and right shift operations.
- **Status flags:** negative, zero, carry and overflow.

## Verification

The laboratory report presents component-level and top-level simulations. It also describes an intermittent discrepancy in the top-level `chk` signal.
