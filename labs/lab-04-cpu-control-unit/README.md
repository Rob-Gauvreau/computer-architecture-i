# Lab 4 — CPU Control Unit

## Overview

Designed a **hardwired CPU control unit** that coordinates instruction execution through timing states, opcode decoding and combinational control logic. The processor model uses an **8-bit datapath** and **256 × 8 memory**.

Key functions include:

- **Register operations:** load, increment and clear controls.
- **Datapath operations:** ALU and bus selections.
- **Memory:** write control and data transfers.
- **Sequencing:** display, fetch and execute phases.

## Documentation

The report contains control-signal equations and gate-level diagrams, while the accompanying control table and laboratory manual explain the timing and instruction requirements.
